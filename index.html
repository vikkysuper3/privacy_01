यह Privacy Policy बताती है कि Sarkari Yojna Info - Guide ऐप उपयोगकर्ता की जानकारी को कैसे संभालता है। इसमें ऐप द्वारा वर्तमान में उपयोग की जा रही local storage, Firebase Cloud Messaging (FCM), बाहरी सरकारी websites और अन्य संबंधित technical services के data handling का विवरण दिया गया है।

महत्त्वपूर्ण सरकारी सूचना अस्वीकरण:

यह ऐप एक स्वतंत्र, गैर-सरकारी सूचनात्मक ऐप है। यह भारत सरकार, किसी राज्य सरकार, मंत्रालय, विभाग, सरकारी agency या अन्य सरकारी संस्था का official app नहीं है और किसी सरकारी संस्था से संबद्ध, अधिकृत या समर्थित होने का दावा नहीं करता।

ऐप स्वयं किसी सरकारी योजना की स्वीकृति, सरकारी लाभ का वितरण, form verification, payment या financial transaction प्रदान नहीं करता। योजना संबंधी जानकारी सार्वजनिक रूप से उपलब्ध सरकारी sources से reference के लिए प्रस्तुत की जाती है।

1. हम कौन-सी Personal Information एकत्र करते हैं?

ऐप में user account, login या registration की सुविधा नहीं है। ऐप सामान्य उपयोग के लिए आपका नाम, पता, आधार नंबर, bank account number, contact list, photo, camera data, microphone data या precise location मांगता या अपने स्वयं के server पर संग्रहीत नहीं करता।

हालाँकि, ऐप में push notifications उपलब्ध कराने के लिए Firebase Cloud Messaging (FCM) का उपयोग किया जाता है। Notification delivery के लिए Firebase द्वारा आवश्यक technical information, जैसे Firebase Installation ID तथा notification token या समान technical identifiers, process किए जा सकते हैं।

2. Firebase Cloud Messaging (FCM)

ऐप में Firebase Cloud Messaging का उपयोग सार्वजनिक योजना-संबंधी सूचनाओं, समाचार और अन्य app notifications को उपयोगकर्ताओं तक पहुँचाने के लिए किया जाता है।

FCM notification delivery को सक्षम करने के लिए device/app से संबंधित technical identifiers या notification token process कर सकता है। इन identifiers का उपयोग notification भेजने और संबंधित notification functionality को संचालित करने के लिए किया जाता है।

ऐप Firebase का उपयोग उपयोगकर्ता से आधार नंबर, bank details, contacts, photo, microphone data या precise location एकत्र करने के उद्देश्य से नहीं करता।

Firebase और Google की संबंधित services अपने infrastructure, security, abuse prevention तथा service operation के लिए technical information को अपनी लागू policies के अनुसार process कर सकती हैं।

Firebase की data handling के बारे में अधिक जानकारी के लिए Google की Privacy Policy देखें:

https://policies.google.com/privacy

3. Notifications

ऐप में सरकारी योजनाओं, योजना updates, समाचार और अन्य सार्वजनिक सूचना से संबंधित push notifications भेजी जा सकती हैं।

Notification delivery के लिए आवश्यक technical information, notification token या संबंधित identifier Firebase Cloud Messaging द्वारा process किया जा सकता है।

Notifications का उद्देश्य केवल ऐप की घोषित सूचना सुविधाओं को उपलब्ध कराना है। ऐप notifications के माध्यम से किसी सरकारी संस्था की official representative होने का दावा नहीं करता।

4. स्थानीय Bookmarks और पसंदीदा योजनाएँ

ऐप में योजनाओं को bookmark या favorite करने की सुविधा उपलब्ध है। इसके लिए आवश्यक जानकारी आपके device पर local रूप से संग्रहीत की जाती है।

Bookmark data को किसी user account के रूप में हमारे server पर upload नहीं किया जाता। यह local app storage/database में रहता है।

यदि आप ऐप का data clear करते हैं या ऐप uninstall करते हैं, तो local रूप से संग्रहीत bookmarks और preferences हट सकते हैं।

5. योजना संबंधी सार्वजनिक जानकारी

ऐप में सरकारी योजनाओं से संबंधित सार्वजनिक जानकारी उपलब्ध कराई जाती है। योजना संबंधी remote/public content उपलब्ध होने पर network request के लिए आवश्यक technical information hosting, Firebase या संबंधित infrastructure द्वारा process की जा सकती है।

योजना data में उपयोगकर्ता की निजी जानकारी शामिल करने का उद्देश्य नहीं है।

6. बाहरी सरकारी Websites के Links

ऐप में सरकारी योजनाओं और सरकारी कार्यक्रमों से संबंधित बाहरी सरकारी websites तथा portals के links दिए जाते हैं।

जब आप किसी बाहरी website को खोलते हैं, तो आप संबंधित third-party website या government portal पर चले जाते हैं। उस website द्वारा एकत्र, उपयोग या संग्रहीत किए जाने वाले data पर उसकी अपनी Privacy Policy और terms लागू होती हैं।

हम बाहरी websites की cookies, tracking, data collection, processing या retention practices को नियंत्रित नहीं करते।

7. Data का उपयोग

ऐप उपलब्ध data और technical information का उपयोग केवल ऐप की सुविधाएँ संचालित करने के लिए करता है, जैसे:

  • योजना संबंधी सार्वजनिक जानकारी उपलब्ध कराना
  • Bookmark की गई योजनाओं को device पर उपलब्ध कराना
  • Push notifications भेजना
  • योजना या सार्वजनिक सूचना updates उपलब्ध कराना
  • ऐप की आवश्यक technical services को संचालित करना

हम उपयोगकर्ता की Personal Information को बेचने या किराये पर देने का उद्देश्य नहीं रखते।

8. Data Sharing

ऐप में user account या ऐसा कोई personal profile system नहीं है जिसमें उपयोगकर्ता द्वारा दिया गया नाम, पता, आधार या bank details हमारे server पर संग्रहीत किया जाए।

Notification और आवश्यक technical services के लिए Firebase जैसे third-party service providers द्वारा आवश्यक technical information process की जा सकती है।

ऐप Personal Information को बिक्री के उद्देश्य से third parties को नहीं बेचता।

9. Data Security

Local bookmark और preference data Android के सामान्य application storage/database protections के अधीन device पर संग्रहीत रहता है।

Network communications के लिए HTTPS जैसे standard secure communication mechanisms का उपयोग किया जाता है जहाँ संबंधित service द्वारा उपलब्ध कराया जाता है।

फिर भी कोई भी device, network या digital system पूर्णतः जोखिम-मुक्त नहीं माना जा सकता।

10. Data Retention और Deletion

Local bookmark data आपके device पर तब तक रह सकता है जब तक आप उसे ऐप की उपलब्ध सुविधाओं के माध्यम से हटाते नहीं हैं, ऐप का data clear नहीं करते या ऐप uninstall नहीं करते।

ऐप में user account नहीं है। इसलिए account deletion प्रक्रिया लागू नहीं होती।

Firebase द्वारा process किए जाने वाले technical identifiers और notification-related information का retention संबंधित Firebase services की लागू policies और technical operation के अनुसार हो सकता है।

11. विज्ञापन और Analytics

ऐप में AdMob या किसी advertising network का उपयोग नहीं किया जाता। ऐप उपयोगकर्ता को targeted advertising देने के लिए Personal Data का उपयोग नहीं करता।

ऐप में Firebase Analytics को user analytics के लिए सक्रिय नहीं किया गया है।

12. बच्चों की Privacy

यह ऐप विशेष रूप से बच्चों को लक्षित करके डिज़ाइन नहीं किया गया है। हम जानबूझकर बच्चों से Personal Information एकत्र करने का उद्देश्य नहीं रखते।
